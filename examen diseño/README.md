# EcoMacas - Agencia de Turismo

- Nombre del proyecto: EcoMacas - Agencia de Turismo ficticia
- Nombre del estudiante: Misan Rivas
- Destino turístico asignado: Macas, Morona Santiago — cultura amazónica, naturaleza, cascadas y turismo de aventura
- Tipo de proyecto: Sitio web ficticio desarrollado como actividad académica

## Descripción del proyecto

Este sitio web presenta a EcoMacas como una agencia turística ficticia creada para cumplir con la actividad académica sobre turismo en Macas, Morona Santiago. El proyecto promociona atractivos naturales, experiencias culturales, paquetes turísticos y un formulario de contacto para reservas hipotéticas. Fue desarrollado con HTML5 y CSS3, siguiendo la estructura semántica y la responsividad exigidas para la evaluación.

## Tecnologías utilizadas

- Git y GitHub

## Captura del sitio

El sitio puede abrirse localmente en el navegador desde la carpeta del proyecto o publicarse en GitHub Pages.

## URL del sitio publicado

Para publicarlo en GitHub Pages, crea un repositorio público y activa la opción de Pages desde Settings > Pages. La URL final tendrá este formato:

https://usuario.github.io/nombre-del-repositorio/

Ejemplo:

https://Misan-sys.github.io/AGENCIA-DE-TURISMO-EN-MACAS/

## Requisitos cubiertos

- 5 páginas HTML diferentes
- Menú principal y footer en todas las páginas
- Diseño responsive con media queries
- Formulario HTML5 con label, required, type email, tel, date y select
- Tarjetas con grid/flexbox y estilos visuales con CSS3
- Uso de pseudo-clases hover y focus
- Información turística realista sobre Macas y Morona Santiago
